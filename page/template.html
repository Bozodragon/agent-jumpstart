Set up your agent

Work through the steps in order. Where there's a box, click the line, press Ctrl+C and paste it where the box says.

Set up

3 steps

  1. Paste the line

    Open Windows PowerShell from the Start menu, paste this and press Enter. You don't need admin rights, and running it again is safe.

    Install lineClick the line, then press Ctrl+C
    See what this runs
    >{{pastedLine}}

    After you press Enter, nothing may appear for up to half a minute. That wait is Windows PowerShell fetching the script, before our installer starts. Leave the window open.

    It asks a few questions, and pressing Enter picks the usual answer. When you need to sign in to something, it opens the page, says what to click and waits for you. It ends with a checklist of what it set up.

  2. Type /jumpstart in your top workspace

    Open T3 Code from the Start menu. Your top workspace, {{topWorkspace}}, is already in its list, because the installer added it. Start a new conversation there, type /jumpstart and press Enter.

    The agent gets to know you and your work, asks a few questions, shows you what it found so you can correct it, then sets up your other workspaces.

  3. Open Personal assistant and start a conversation

    Personal assistant is now in T3 Code's list too. Open it, start a conversation and ask for what you need, such as "Help me plan today".
