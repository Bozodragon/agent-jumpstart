# Skills

Skills the installer installs from this repo with the skills CLI, listed in each profile's `skills`.

| Skill | What it's for |
| --- | --- |
| `jumpstart/` | Run once as `/jumpstart` in the top workspace: learns who the person is, shows the profile for approval. Its help categories are in `jumpstart/help-categories.md`, the research prompt in `jumpstart/research-brief.md`, and the profile page in `jumpstart/profile-page.html`. |
